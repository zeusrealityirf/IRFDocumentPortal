# IRF Government Document Editor

A static website for preparing Prime Minister’s Decrees and Decrees of Appointment.

## Files

- `index.html` — document templates and editor controls.
- `styles.css` — screen, A4 and print layouts.
- `editor.js` — editing, pagination, signature uploads and exports.
- `assets/` — government logo and imperial eagle.

## GitHub Pages

Upload the contents of this folder to the root of your repository, including the `assets` folder. Commit the files. If Pages is already enabled, no settings need changing. Otherwise choose Settings → Pages → Deploy from a branch → main → /(root).

The site is static. No server-side application, database or third-party libraries are needed. Signatures and documents are processed in the browser. For local offline use, open the standalone HTML version instead of this multi-file source.
